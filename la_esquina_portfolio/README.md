# La Esquina — Proyecto de portafolio

Página web ficticia para una cafetería, creada como proyecto de práctica de desarrollo frontend.

## Tecnologías
- HTML5
- CSS3
- Diseño responsive para computadoras, tablets y celulares

## Cómo verla
Abrí `index.html` en tu navegador.

## Personalización
- Los textos, precios y datos de contacto son ficticios.
- Las imágenes se cargan desde Unsplash y requieren conexión a internet.
- Podés cambiar los datos de ejemplo por contenido propio antes de publicar.

## Publicar con GitHub Pages
1. Subí `index.html`, `styles.css` y `README.md` al repositorio.
2. En GitHub, abrí **Settings → Pages**.
3. En **Build and deployment**, seleccioná **Deploy from a branch**.
4. Elegí la rama `main` y la carpeta `/ (root)`, y guardá.
5. Esperá a que GitHub Pages publique el sitio.
